# ADDC-Journey

Learning **Analysis and Design of Digital Circuits (ADDC)**: digital logic, Verilog HDL, simulation and FPGA implementation. This repo is my public log from Oct 2026 to Feb 2027, with the goal of landing an internship by the end of my 4th semester.

## Goal
- Build solid ADDC skills: combinational and sequential design, FSMs, memory, timing
- Ship 3 projects: an FPGA mini project, UART, and an 8-bit CPU capstone
- Document everything with code, testbenches and waveforms

## Tools
- Vivado (simulation, synthesis, implementation)
- Vitis
- HDLBits for daily practice
- Git and GitHub

## Folder guide
| Folder | What is inside |
|--------|----------------|
| `rtl/` | Verilog design files |
| `tb/` | Testbenches |
| `sim/` | Waveform screenshots |
| `fpga/` | Constraints and board notes |
| `docs/` | Diagrams, notes, state diagrams |
| `other/` | Older Python practice scripts |



## Daily routine
Theory, coding, simulation, HDLBits, project work, a longer weekend block
